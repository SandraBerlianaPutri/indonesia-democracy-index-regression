# Factors Influencing Indonesia's Democracy Index in 2022

## About
This project uses multiple linear regression to examine factors associated with Indonesia's Democracy Index in 2022.

## Project Analysis
- [**View Full Analysis on RPubs**](https://rpubs.com/sandraberlianaputri/regression-democracy-index-provinces)

## Methods
- **Exploratory Data Analysis:** Descriptive statistics, boxplots, and correlation matrix.
- **Initial Modeling:** Multiple linear regression with nine explanatory variables.
- **Predictor Selection:** Correlation analysis and Variance Inflation Factor (VIF).
- **Regression Diagnostics:** Studentized residuals, leverage, and DFFITS to identify potential outliers and influential observations.
- **Assumption Testing:** Residual mean, homoscedasticity (Breusch–Pagan), error independence (Durbin–Watson), and normality (Q–Q plot and Kolmogorov–Smirnov test).
- **Model Selection:** Forward, backward, stepwise, and best subset regression.
- **Model Evaluation:** Coefficient t-tests, overall F-test, adjusted R-squared, and residual diagnostics.
